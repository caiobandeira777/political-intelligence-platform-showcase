# Mandato365 — Political Intelligence Platform

Mandato365 is a political intelligence platform built to help parliamentary offices and campaigns transform fragmented public data into strategic decisions.

The platform combines electoral records, public spending data, census indicators, news monitoring, social media analytics and AI-generated insights into one centralized dashboard.

## Features

* AI-powered news clipping and sentiment classification
* Social media analytics for Instagram, TikTok and X/Twitter
* Opponent monitoring and viral content detection
* Electoral maps with municipal-level performance indicators
* Public budget and amendment tracking
* Speech generation based on regional census data
* Data-driven dashboards for political strategy

## Tech Stack

* Next.js
* TypeScript
* PostgreSQL
* AI integrations
* Public data pipelines
* Data visualization
* Production deployment

## Confidentiality Notice

The production source code is private because Mandato365 is an active product used by a real parliamentary office and political party.
